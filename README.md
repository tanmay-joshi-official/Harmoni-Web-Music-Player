# 🎧 Harmoni – Web Music Player

Harmoni is a **Spotify-inspired web music player** built completely using **HTML, CSS, and Vanilla JavaScript**. The goal of this project was to deeply understand how a real-world music streaming interface works on the **frontend**, including audio playback, UI state management, and responsive layouts — without using any frameworks or backend services.

This project is designed as a **major frontend learning project** and focuses on clean UI, smooth user interaction, and original branding.

> ⚠️ **Disclaimer**: This project is created strictly for **learning and educational purposes**. All audio used in this project is sourced from **Pixabay (royalty-free music)**.

## 🧰 Tech Stack

### Frontend

* **HTML5** – Semantic structure and layout
* **CSS3** – Flexbox, responsive design, animations, dark-themed UI
* **JavaScript (ES6)** – DOM manipulation, event handling, application logic

### APIs & Browser Features

* **HTML5 Audio API** – Audio playback, seek control, duration tracking

> ⚠️ No frameworks, libraries, or backend services are used.

---

## ✨ Features

### 🎵 Music Playback

* Play / Pause functionality
* Next & Previous track navigation
* Dynamic song loading
* Real-time progress bar with seek control
* Track duration display
* Volume control with mute / unmute

### 📂 Playlists & UI

* Playlist cards with album artwork and descriptions
* Curated playlists under "Playlists for You"
* Individual song list rendering per playlist
* Spotify-inspired dark UI design

### 🍔 Navigation & Layout

* Slide-in sidebar menu
* Hamburger menu for smaller screens
* Fixed bottom music player bar
* Fully responsive layout across devices

### 🎨 Branding

* Custom project name: **Harmoni**
* Original logo and favicon
* No copyrighted brand assets used

## 📁 Project Structure

```
Harmoni/
│── index.html        # Main HTML structure
│── style.css         # Global styles and UI layout
│── utility.css       # For utility classes
│── script.js         # Application logic and audio handling
│── Assets            # Contains all the icons
│── Songs/
│   ├── All playlist folder/       # Folders of all the playlists used
│       └── info.json              # For dynamic album display
│       └── cover.png              # Album cover
```

## 🚧 Known Limitations

* This is a **frontend-only** project
* No user authentication or personalization
* Playlists are dynamically loaded using the songs folder through localhost
* No backend or database integration

These limitations are intentional to keep the focus on frontend development.
